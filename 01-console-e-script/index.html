Como funciona?

JavaScript é uma linguagem que pode ser executada pelo navegador para dar comportamento às páginas.

Como acontece?

  • HTML organiza o conteúdo.
  • CSS apresenta o conteúdo.
  • JavaScript executa instruções e cria comportamentos.
  • O arquivo script.js é carregado pelo HTML.
