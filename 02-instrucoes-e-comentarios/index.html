Script, Console e instruções

Uma instrução é uma ordem que o JavaScript executa. O comentário explica o código, mas não é executado.

Observe no arquivo JavaScript

// Este comentário não aparece como resultado.
console.log("Esta é uma instrução");
console.log(2 + 3);
Altere o texto e o cálculo. Salve, recarregue e veja a diferença no Console.
