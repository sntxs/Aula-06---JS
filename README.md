# Aula 10 — JavaScript ES6 por etapas

Projeto didático para conduzir a aula de JavaScript ES6 do zero.

## Ordem sugerida

1. `01-console-e-script`: programação no navegador e conexão do JavaScript.
2. `02-instrucoes-e-comentarios`: Console, instruções e comentários.
3. `03-variaveis`: `let`, `const` e `var` como contexto histórico.
4. `04-tipos-e-operadores`: tipos de dados e operadores.
5. `05-strings-e-template-literals`: textos e interpolação de valores.
6. `06-decisoes-if-else`: decisões com `if` e `else`.
7. `07-desafio-integrador`: exercício final combinando os conteúdos.

## Escopo desta aula

O projeto trabalha somente:

- programação no navegador;
- arquivo `script`;
- Console;
- instruções e comentários;
- `let`, `const` e `var` histórico;
- tipos;
- operadores;
- strings;
- template literals;
- `if` e `else`.
