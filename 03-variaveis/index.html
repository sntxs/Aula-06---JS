let, const e var

Variáveis guardam valores para que o programa possa utilizá-los depois.

const

Use quando a variável não será reatribuída.

let

Use quando o valor poderá mudar.

var

Conheça para ler códigos antigos; não é a escolha principal em ES6.

Teste mudar tentativas e observe que nome foi declarado com const.
